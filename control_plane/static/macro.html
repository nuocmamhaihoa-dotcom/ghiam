Click tự động trên PC

VPS này giữ kịch bản thao tác. Ghi phím, bấm chuột và bấm Làm lại phải chạy trên máy tính có màn hình.

Cài trên máy Windows

  1. Tải gói phần mềm, giải nén.
  2. Cài Python 3.11 trở lên nếu máy chưa có.
  3. Mở PowerShell trong thư mục vừa giải nén rồi chạy .\Cai-dat.ps1.
  4. Cửa sổ Ghi / Dừng / Làm lại hiện ra. Bấm Ghi, làm thao tác trên máy, Dừng, rồi Làm lại. F8 cũng dừng.
Tải phần mềm PC

Đưa kịch bản lên VPS

Sau khi cài, đặt địa chỉ kho rồi đẩy bản đã lưu từ máy lên đây:

$env:PC_MACRO_HUB='http://IP:8088'

$env:PC_MACRO_TOKEN=''

Trên máy: nút Lên VPS / Lấy VPS, hoặc:

python -m pc_macro push

python -m pc_macro pull

Chọn file Excel đã tải từ trang này, hoặc file CSV. Cột nhận: Số điện thoại, Tên, Username, Loại, Lý do, Đọc bởi, Đọc lúc (giờ VN).

Dòng đã lưu đủ tên và username từ một video thì giữ nguyên. Dòng chưa mở hồ sơ hoặc cần xem được nâng lên đã lưu khi file có đủ số, tên và username. File tối đa 20 MB và 100000 dòng.

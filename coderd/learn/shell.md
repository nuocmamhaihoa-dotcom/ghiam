# Lệnh trong workspace

Thư mục hiện tại là workspace. Không đọc file ngoài đó.

- Liệt kê: `ls`
- Xem file: `python3 -c 'print(open("a.txt", encoding="utf-8").read())'`
- Chạy Python: `python3 hello.py`
- Tìm chữ: `grep -n "ten" -r .`

Lệnh tối đa 30 giây. Lệnh dài sẽ bị dừng.
Không dùng sudo. Không xóa file hệ thống.

# Mục lục học của coderd

Đọc đúng một file khi cần. Không đọc hết một lúc.

- nguon-api.md: các API coderd gọi được, và API đang chạy.
- nguon-hoc.md: kho học mở để đọc hoặc huấn luyện sau.
- python.md: Python ngắn cho việc sửa code.
- shell.md: lệnh trong workspace.
- git.md: git trên máy này.

Việc cần nhớ cho lần sau thì ghi vào `.coderd/memory.md`.
